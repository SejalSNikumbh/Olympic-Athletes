# 🏅 Olympic Medals Dashboard (Tableau)

## 📊 Overview

This project is an **interactive data visualization dashboard** built using **Tableau** to explore and analyze Olympic medal distributions across various countries, years, and sports. It allows users to discover trends, compare country performances, and understand the evolution of Olympic games through dynamic filters and KPIs.

---

## 🎯 Objectives

- Analyze medal counts by country, year, and sport  
- Identify top-performing countries and athletes  
- Visualize trends across Summer and Winter Olympics  
- Create an interactive and user-friendly Tableau dashboard

---

## 🔧 Tools & Technologies

- **Tableau Public**  
- **Excel / CSV** (for raw data preprocessing)  
- **Data Cleaning & Preprocessing**

---

## 📁 Features

- 📌 Filters for **Year**, **Country**, and **Sport**  
- 🥇 KPIs for **Total Medals**, **Golds**, **Silvers**, **Bronzes**  
- 📈 Visualizations: Bar charts, line graphs, and heatmaps  
- 🌍 Country-wise medal distribution maps

---

## 🧹 Data Preparation

- Cleaned missing or inconsistent data using Excel  
- Removed duplicate records and formatted country names  
- Converted raw tables into usable datasets for Tableau
